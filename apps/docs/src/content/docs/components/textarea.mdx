---
title: Textarea
description: Multiline text input with accessible styles.
---

## Installation

```package-install
npx @catalix/cli@latest add textarea
```

## Usage

```tsx title="page.tsx" lineNumbers
import Textarea from "@/components/core/textarea"; //[!code ++]

export default function Example() {
  return <Textarea placeholder="Type your message here." />; //[!code ++]
}
```
